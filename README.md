# 데이터 보관소

과제 파일과 사진을 정리할 공간이 필요한 학생과 개인 사용자를 위한 서비스입니다. 저장 용량을 선택하고 파일을 추가·삭제하면서 보관함의 사용량을 확인할 수 있습니다.

- GitHub 저장소: https://github.com/koodonghyeon/uiuxprogramming
- 배포 웹페이지: https://koodonghyeon.github.io/uiuxprogramming/

## 이번에 추가한 기능

7주차에는 용량과 이메일을 입력하고 신청 내용을 확인하는 과정까지 만들었습니다. 이번에는 신청 완료 화면에 **파일 보관함 체험하기**를 추가해서, 선택한 용량 안에서 파일을 추가·삭제하고 남은 공간을 확인할 수 있게 했습니다.

단순히 신청하고 끝나는 것보다, 파일을 보관하면 화면이 어떻게 바뀌는지 직접 확인할 수 있도록 하는 데 중점을 뒀습니다. 파일을 추가했을 때 목록과 사용량에 반영되면 보관이 완료된 것으로 표시합니다.

## 사용 방법

1. ‘소식 신청 시작하기’를 누르고 관심 용량과 이메일을 입력합니다.
2. 확인 화면에서 내용을 확인하고 ‘소식 신청하기’를 누릅니다. 잘못 입력한 내용은 이전 단계로 돌아가 수정할 수 있습니다.
3. 신청 완료 화면에서 ‘파일 보관함 체험하기’를 누릅니다.
4. 파일을 선택한 뒤 ‘보관함에 추가’를 누르면 파일명, 크기, 사용량이 표시됩니다.
5. 필요 없는 파일을 삭제하면 그만큼 남은 용량이 늘어납니다.

용량은 10GB, 100GB, 1TB 중에서 고를 수 있습니다. 직접 파일을 선택하지 않아도 사용할 수 있도록 6GB 동영상과 5GB 사진 모음 예시를 넣었습니다. 예시는 실제 파일 대신 정해진 크기로 용량을 계산합니다.

## 동작과 예외 처리

파일 선택에는 `change`, 추가에는 `submit`, 삭제와 취소에는 `click` 이벤트를 연결했습니다. 추가하기 전에 파일이 선택됐는지, 빈 파일이나 중복 파일은 없는지, 남은 용량 안에 들어가는지 확인합니다.

| 상황 | 화면 반응과 다음 행동 |
| --- | --- |
| 정상 파일 추가 | 파일 목록과 개수, 사용량을 갱신합니다. 이어서 다른 파일을 추가하거나 삭제할 수 있습니다. |
| 파일을 선택하지 않음 | 먼저 파일을 선택하라는 안내를 보여줍니다. 예시 파일로 시작할 수도 있습니다. |
| 내용이 없는 0 B 파일 | 추가하지 않고 내용이 있는 파일을 다시 선택하도록 안내합니다. |
| 중복 파일 | 중복 안내를 보여줍니다. 다른 파일을 선택하거나 기존 항목을 삭제한 뒤 다시 추가할 수 있습니다. |
| 용량 초과 | 필요한 용량과 남은 용량을 표시합니다. 기존 파일을 삭제하거나 더 작은 파일을 선택해야 합니다. |
| 파일 삭제 | 목록에서 해당 항목을 없애고 용량을 다시 계산합니다. 마지막 파일을 지우면 빈 보관함 안내를 보여줍니다. |
| 선택 취소 | 아직 추가하지 않은 선택만 취소합니다. 이미 보관한 파일은 남습니다. |
| 체험 초기화 | 모두 비울지 먼저 확인합니다. 확인하면 목록과 사용량을 초기화하고, 취소하면 그대로 유지합니다. |

중복 여부는 파일 이름, 크기, 마지막 수정 시각으로 판단합니다. 여러 파일을 한꺼번에 선택했을 때 하나라도 조건에 맞지 않으면 이번 선택은 모두 추가하지 않고 기존 목록을 유지합니다.

신청 완료 화면으로 돌아갔다가 보관함을 다시 열어도 파일 목록과 선택 중인 파일은 남아 있습니다. ‘체험 초기화’는 보관함만 비우고, 신청 화면의 ‘다시 시작하기’는 이메일과 용량을 포함한 전체 과정을 초기화합니다.

## 확인한 내용

로컬 페이지를 Edge와 Playwright로 다시 확인했습니다. 화면 너비는 1100px, 768px, 390px이며, 390px은 실제 휴대전화 대신 브라우저의 터치 에뮬레이션으로 테스트했습니다.

| 테스트 | 결과 |
| --- | --- |
| 신청 후 보관함 열기 | 신청한 용량과 이메일이 표시됨 |
| 파일 2개 추가 | 파일 목록에 두 개가 표시되고 크기의 합계가 사용량에 반영됨 |
| 미선택, 빈 파일, 중복 파일 추가 | 안내가 표시되고 기존 목록과 사용량은 바뀌지 않음 |
| 10GB 보관함에 6GB 추가 후 5GB 추가 | 남은 공간이 4GB라서 두 번째 파일은 추가되지 않음 |
| 6GB 파일 삭제 후 대기 중인 5GB 추가 | 공간이 확보되고 5GB 파일 추가에 성공함 |
| 한도에 맞는 파일과 1 B 초과 파일 | 한도에 정확히 맞으면 추가되고, 초과하면 차단됨 |
| 마지막 파일 삭제 | 사용량이 0으로 바뀌고 빈 보관함 안내가 표시됨 |
| 선택 취소, 초기화 취소 | 취소 대상 외의 파일과 선택값은 유지됨 |
| 보관함 초기화, 신청 다시 시작 | 각각 정해진 범위의 입력값과 목록, 오류 상태가 초기화됨 |
| 완료 화면으로 돌아갔다가 재진입 | 보관 목록과 선택 중인 파일이 유지됨 |
| 100GB와 1TB에서 예시 두 개 추가 | 합계 11GB로 계산되고 선택한 전체 용량이 적용됨 |
| 긴 파일명과 이메일 표시 | 줄바꿈되어 표시되며 입력창과 버튼이 화면 밖으로 밀리지 않음 |
