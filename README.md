# 데이터 보관소 — 6주차 JavaScript 이벤트와 동적 UI

사진, 문서, 과제 파일을 한곳에서 관리하는 데이터 보관 서비스의 소개 페이지입니다. 5주차 페이지의 디자인과 이미지를 유지하면서 서비스에 맞는 콘텐츠, 세 개의 탭, 저장 용량 선택 체험을 추가했습니다.

## 구현한 이벤트와 화면 변화

| 이벤트 | 사용자 행동 | 함께 바뀌는 화면 상태 |
| --- | --- | --- |
| `click` | 파일 보관 / 용량 선택 / 이용 안내 탭 클릭 | 선택 탭의 배경·글자색 및 `aria-selected` 변경, 연결된 콘텐츠만 표시 |
| `change` | 저장 용량을 10GB / 100GB / 1TB로 변경 | 용량명·추천 용도 변경, 요약 카드 강조, 버튼 활성화 및 문구 변경 |
| `click` | 선택 완료 버튼 클릭 | 완료 문구, 초록색 요약 카드, 버튼 비활성화 및 ‘선택 완료’ 문구 표시 |
| `input` | 이메일 입력·수정·삭제 | 유효성 안내 문구, 입력란·안내 문구 색상, 신청 버튼 활성/비활성 상태 변경 |
| `submit` | 유효한 이메일 입력 후 신청 체험 | 새로고침 방지, 신청한 이메일 주소를 포함한 완료 안내, 버튼 문구 변경 및 중복 제출 방지 |
| `keydown` | 탭에서 좌우 방향키 / Home / End | 탭 선택과 포커스 이동, 연결된 콘텐츠 표시 |

### 상태 처리

- 용량 미선택: 기본 안내를 표시하고 선택 완료 버튼을 비활성화합니다.
- 용량 선택: 추천 용도와 파란색 카드를 표시하고 버튼을 활성화합니다.
- 선택 완료 후 다른 용량 선택: 완료 상태를 해제하고 다시 선택할 수 있습니다.
- 빈 이메일: 기본 안내, 기본 입력란 스타일, 비활성 버튼을 표시합니다.
- 잘못된 이메일: 오류 안내, 붉은 입력란, `aria-invalid="true"`, 비활성 버튼을 표시합니다.
- 유효한 이메일: 성공 안내, 초록색 입력란, 활성 버튼을 표시합니다. HTML `type="email"`의 기본 유효성 검사를 사용합니다.
- 신청 체험 완료 후 이메일 수정: 입력값을 다시 검사하고 유효한 경우 버튼을 활성화합니다.

## 탭과 반응형 구현

- `role="tablist"`, `role="tab"`, `role="tabpanel"`, `aria-controls`, `aria-labelledby`로 탭과 콘텐츠를 연결했습니다.
- `hidden` 속성과 `[hidden]` 스타일로 선택하지 않은 콘텐츠를 숨겼습니다.
- 키보드 포커스 표시와 `aria-live="polite"` 안내를 추가했습니다.
- 768px 이하에서는 소개, 메뉴, 이메일 폼을 세로로 배치합니다. 420px 이하에서는 여백과 탭 글자 크기를 조정합니다.
- `minmax(0, 1fr)`, 유동 너비, 이미지 최대 너비를 적용하여 콘텐츠가 화면 밖으로 밀려나지 않도록 했습니다.
